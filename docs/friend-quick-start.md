# 发给朋友的简短说明

这是 OLDBAI FF14 国服插件合集。

安装方法：

1. 进游戏后打开卫月设置。
2. 找到“实验性功能 / 第三方插件仓库”。
3. 添加这个地址：

```text
https://raw.githubusercontent.com/OLDBAI213/OLDBAI/Main-Branch/pluginmaster.json
```

4. 保存后打开插件安装器。
5. 搜索需要的中文插件名：

```text
宇宙探索助手
生产制作助手
自动钓鱼
采集与钓鱼资料库
导航寻路基础
```

要求：

- 国服 XIVLauncherCN。
- 卫月环境需要 API 15。
- 如果列表里搜不到，先刷新插件列表或重启一次游戏。
