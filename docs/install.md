# OLDBAI 插件合集安装说明

## 推荐安装：添加卫月第三方仓库

仓库地址：

```text
https://raw.githubusercontent.com/OLDBAI213/OLDBAI/Main-Branch/pluginmaster.json
```

使用方法：

1. 启动 XIVLauncherCN 并进入游戏。
2. 打开卫月设置。
3. 进入“实验性功能 / 第三方插件仓库”。
4. 添加上面的仓库地址并保存。
5. 打开卫月插件安装器并刷新列表。
6. 搜索中文插件名并安装：

```text
宇宙探索助手
生产制作助手
自动钓鱼
采集与钓鱼资料库
导航寻路基础
```

## 插件分别做什么

| 中文名 | 作用 |
|---|---|
| 宇宙探索助手 | 宇宙探索任务、制作、采集和模式辅助 |
| 生产制作助手 | 制作队列、制作模拟、宏、自动制作和制作诊断 |
| 自动钓鱼 | 自动抬杆和钓鱼流程辅助 |
| 采集与钓鱼资料库 | 采集点、鱼类、天气、时限点、闹钟和路线资料 |
| 导航寻路基础 | 本地导航网格和自动寻路基础能力 |

## 手动安装：只在仓库刷新失败时使用

优先使用第三方仓库安装。手动安装只用于测试指定 zip 或 GitHub Release 可下载但插件仓库刷新失败的情况。

1. 完全退出 FF14 和 XIVLauncherCN。
2. 打开目录：

```text
%APPDATA%\XIVLauncherCN\installedPlugins
```

3. 根据 zip 名称新建对应目录，例如：

```text
Artisan\4.0.5.15
AutoHook\6.0.0.46
GatherbuddyReborn\7.5.0.2
vnavmesh\0.6.5.0
ICE\0.0.78.7000
```

4. 把对应 zip 里的所有文件解压到对应版本目录。
5. 重新启动 XIVLauncherCN 和游戏。
6. 打开卫月插件列表，找到中文插件名并启用。

## 常见问题

### 插件不显示

- 确认第三方仓库地址没有多空格。
- 确认当前使用的是国服 XIVLauncherCN。
- 重新打开插件安装器并刷新插件列表。

### 插件加载失败

- 确认卫月是 API 15 环境。
- 确认没有同时保留多个手动安装的旧版本目录。
- 先删除手动安装目录，再使用第三方仓库重新安装。

### 插件还是英文

- 插件安装器列表里的名称和说明应显示中文。
- 插件内部界面是否全中文取决于插件本身资源；当前仓库优先保证仓库清单和已可分发资源中文化。
- `AutoHook` 包含内置 `zh` 资源目录。
- `Artisan` 当前发布包来自本机已汉化/已安装运行文件，后续更新应继续从中文构建产物打包。
